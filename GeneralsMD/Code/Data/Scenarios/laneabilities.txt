# Lane War abilities proof: every wave unit presses its own buttons, on the skirmish AI's rules and
# the lane's walk-up rule, as far as its player's switches let it. Team A fields the units with a
# button (Burton, Missile Defenders, Tank Hunters, Black Lotus, a Hacker, a Dragon, Jarmen Kell,
# Hijackers), team B nothing but Crusaders. Read the LANEWAR ABILITY USE lines, the LANEWAR ABILITY
# lines for the switches and for a hijacked Crusader marching for its taker, and the IDLEHACKER lines
# (there should be none: a plot's hacker is held and must not hack for money).
#
#   generals.exe -headless -quickstart -noshellmap -observer -multiInstance -noFPSLimit
#     -randommap 3 lane -autoskirmish 6 -takeover -side 0 FactionAmerica -side 1 FactionAmerica
#     -side 2 FactionChina -side 3 FactionAmerica -side 4 FactionGLA -side 5 FactionAmerica
#     -seed 1 -maxframes 21000 -scenario laneabilities -logPrefix laneabilities_
#
# laneabilities_off.txt is the same match with every one of those buttons switched off. Slots 0, 2
# and 4 are team A's three seats, 1, 3 and 5 team B's. A laneability line is <slot> <template>
# <command set slot> <0|1>; the slot is the button's place in the unit's own command set counted
# from 0, the INI's number less one (Black Lotus's cash hack is the INI's 5, so 4 here). The
# frames are this file's 30 Hz frames, which the drill scales by the game speed (15000 here is logic
# frame 10000 at the native 1.5x). Nothing is ordered after 15000, so a save taken past logic frame
# 10000 and loaded again plays the rest as the whole run does.
