# the only one in the field; it meets in the middle and walks on into the towers.
#
#   generals.exe -headless -quickstart -noshellmap -observer -multiInstance -noFPSLimit
#     -randommap 3 lane -autoskirmish 2 -takeover -side 0 FactionAmerica -side 1 FactionChina
#     -seed 1 -maxframes 7000 -scenario lanewar_strays -logPrefix lanewar_strays_
#

#    follows within a frame (if the Crusader lives to 6600 the pilot still shows, the frame after its
#    lifespan kills it, and dies on the next);
#  - the HEADLESS TALLY lines at file 7000 show the Red Guards and the pilot alive with 0 inside once
#    the Crawler is down (outside, so marching), and the lines at file 10000 (logic 6667) show 0 alive

#  - no LANEWAR ABILITY line says either is "player N's now" (adopted with their own player, they
#    march for him from the first idle look, not as a hijack).
