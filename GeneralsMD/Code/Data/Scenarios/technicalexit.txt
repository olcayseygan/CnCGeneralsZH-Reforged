# A GLA Arms Dealer builds a Technical and the Technical comes out, for every dealer a seat can own.
#
# Seat 0 gets the plain, Toxin and Stealth Arms Dealers side by side, so the faction in seat 0 decides
# the case: a plain GLA seat, a Toxin seat and a Stealth seat each build from their own dealer and
# from the other two, the way a captured dealer leaves them. The dealers build one after the other,
# three Technicals each, so a tally after each run says which chassis that dealer made.
#
# What a player queues is a placeholder (GLAVehicleTechnical and its Chem_ and Slth_ twins) and it
# has to come out as a real chassis (...TechnicalChassisOne, Two or Three). The bug was findSideReskin
# picking the placeholder itself: the bar filled, the money went and no unit stood there. A tally on
# a placeholder name above 0, or no chassis at all, is that bug. Every produce line must say
# "queued 3 of 3" and every spawn "1 of 1", or the tallies prove nothing. A Technical takes about
# 500 frames, so each run gets 1500 before its tally.
#
#   generals.exe -headless -quickstart -noshellmap -multiInstance -noFPSLimit
#     -map "Maps\Twilight Flame\Twilight Flame.map" -autoskirmish 2 -takeover
#     -side 0 FactionGLA|FactionGLAToxinGeneral|FactionGLAStealthGeneral -side 1 FactionGLA
#     -seed 7 -maxframes 9400 -scenario technicalexit -logPrefix techexit_
#
